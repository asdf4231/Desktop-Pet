# shaqiu 桌面宠物

一个轻量、透明置顶的 Windows 桌面伙伴：固定角色形象、异步 AI 聊天、系统托盘和三款注意力训练。原图已拆分为头部、身体、左右手臂、左右腿和尾巴图层，因此能单独点头、挥手、摆臂、抬腿和摇尾巴；形象本身和配色均不可修改。

## 快速开始

需要 Python 3.11 或更新版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
.\.venv\Scripts\python desktop_pet.py
```

也可以安装后运行 `shaqiu-pet` 或 `python -m shaqiu_pet`。

## 和 shaqiu 相处

shaqiu 是一个大头的二次元角色，陪着你待在桌面上，而不是一个等你点菜单的工具：

- 它会自己开口。启动几秒后它先打招呼，之后会时不时提醒你喝水、起来走动，或者直接问你「要不要玩一局？」。
  - 想聊天还是想训练注意力，都可以直接在它头顶的气泡下面点答案，不用去翻右键菜单。
  - 点它一下会做出反应；头部、手臂和双腿会按不同动作独立运动。拖动可以换位置；双击直接打开聊天；悬停时脚边会出现快捷按钮。
- 长时间没人理它会打个盹，你一碰它就醒；允许的话它还会自己在桌面上慢慢走动。
- 右键菜单、系统托盘仍然保留，作为备用入口；两处都可以退出 shaqiu。

## 个性化设置

“设置”窗口分成三页，选项都借鉴了成熟桌宠软件的常见做法：

**形象**

| 选项 | 说明 |
| --- | --- |
| 固定形象 | 使用项目内提供的角色图片，不支持替换或配色 |
| 角色大小 | 60%–180%，窗口锚在脚底缩放，位置不会跳 |
| 不透明度 | 30%–100% |
| 始终显示在最前面 | 关掉后它会像普通窗口一样被遮挡 |

**行为**

| 选项 | 说明 |
| --- | --- |
| 允许它自己在桌面上走动 | 打开后它会沿着任务栏慢慢散步 |
| 只有我主动互动时它才移动 | 打开后取消自主走动 |
| 长时间没人理就打个盹 | 关掉后它不会自己睡着 |
| 记住上次待的位置 | 位置存在 `pet_state.json`，且会校验是否还在可见屏幕内 |
| 鼠标穿透 | 点击直接落到下面的窗口；托盘菜单里有同一个开关，方便随时关掉 |
| 开机时自动启动 | 写入当前用户的 `Run` 注册表项，卸载/关闭时会被移除 |
| 主动开口的频率 | 安静 / 正常 / 话多 |

**接口**：模型连接与人设，见下一节。

## 注意力训练

- **舒尔特方格**：5×5 方格先显示 1–25；每点对一个数字，该格原位换成对应的 26–50，最后在同一个棋盘上继续从 26 点到 50。页面记录每次完成用时和最快用时。
- **反应训练**：窗口先显示红色，随机等待后变为绿色；看到绿色时点击窗口任意位置。每次有效反应和最快反应都会保存。
- **动态视力**：开始后短暂闪示随机 6 位数字，数字消失后输入刚才看到的内容，并立即显示正确与否和作答用时。

训练历史保存在系统配置目录的 `training_history.json`，关闭应用后仍会保留。

## API 与隐私

从托盘菜单或聊天窗口打开“接口设置”，填写 OpenAI Chat Completions 兼容的完整 URL、模型和角色设定。API Key 存入系统凭据库；也可通过 `DESKTOP_PET_API_KEY` 环境变量提供。未配置接口时，聊天窗口使用本地演示回复。

配置写在系统配置目录的 `settings.json`，桌宠位置写在同目录的 `pet_state.json`（都可用 `platformdirs` 对应的路径找到）。

风格样本放在项目根目录的 `style_examples.txt`，每次请求会作为人设参考发送。每轮对话只向你配置的 API 服务发送；未配置本地对话持久化。

## 项目结构

```text
src/shaqiu_pet/             应用入口、配置、聊天服务和 Qt 界面
src/shaqiu_pet/autostart.py Windows 开机自启（只写当前用户的 Run 项）
src/shaqiu_pet/assets/      固定角色图片与拆分后的头、身体、四肢、尾巴图层
src/shaqiu_pet/ui/art.py    各身体图层的关节旋转与动作动画
src/shaqiu_pet/ui/palette.py  统一的配色与渐变工具
src/shaqiu_pet/ui/theme.py  全局 QSS 样式表
src/shaqiu_pet/ui/training/ 舒尔特、反应和动态视力训练窗口
src/shaqiu_pet/training.py  舒尔特 1–50 连续训练状态
tests/                     配置、API、桌宠互动和 Qt 渲染测试
.github/workflows/ci.yml   Windows / Python CI
pyproject.toml             依赖、打包与质量检查配置
```
